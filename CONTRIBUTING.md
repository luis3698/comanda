# Contribuir a SIGR

Gracias por tu interés en el proyecto. Antes de nada, ten en cuenta el
contexto: este repositorio se publica como código de referencia y portafolio
(ver [LICENSE](LICENSE)), no como un proyecto de código abierto que reciba
código de terceros.

## Qué sí es bienvenido

- **Reportes de errores (bugs)**: abre un [issue](../../issues/new/choose)
  describiendo qué esperabas que pasara, qué pasó realmente, y los pasos para
  reproducirlo (incluye si fue en el servidor, en la app móvil, o en ambos).
- **Sugerencias de funcionalidad**: abre un issue explicando el problema que
  resolvería y, si tienes una idea, cómo te imaginas que funcione.
- **Preguntas de uso o de arranque del proyecto**: revisa primero la sección
  "Problemas frecuentes" del [README](README.md); si tu caso no está cubierto,
  ábrelo como issue.

## Qué no se acepta por ahora

- **Pull requests con cambios de código**: el proyecto no acepta
  contribuciones externas de código por el momento. Si quieres proponer un
  cambio puntual, abre primero un issue explicándolo — se evaluará caso por
  caso antes de pedir un pull request.

## Código de conducta

Este proyecto sigue el [Código de conducta](CODE_OF_CONDUCT.md); se espera que
toda interacción en issues y discusiones lo respete.
